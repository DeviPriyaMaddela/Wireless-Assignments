# Wireless-Assignments


## 🚀 Overview

This repository contains academic assignments focused on Wireless Network Security and Machine Learning applications in IoT security.
It highlights both traditional security mechanisms and AI-driven threat detection techniques.



## 🔐 Assignment 1

### Security Threats and Defense Mechanisms in Wireless and IoT Networks

### 📌 Highlights

* Common threats in wireless & IoT environments
* Attack types:

  * Eavesdropping
  * DoS (Denial of Service)
  * MITM (Man-in-the-Middle)
* Defense techniques:

  * Encryption (AES, RSA)
  * Authentication protocols
  * Intrusion Detection Systems

### 🎯 Goal

To analyze vulnerabilities and implement strategies for secure communication in IoT systems.

## 🤖 Assignment 2

### Supervised and Unsupervised ML Methods for Securing Smart IoT Systems

### 📌 Highlights

* Supervised Learning

  * Decision Trees
  * Support Vector Machines (SVM)

* Unsupervised Learning

  * K-Means Clustering
  * Anomaly Detection

### 🔍 Applications

* Intrusion detection
* Smart device monitoring
* Threat prediction

### 🎯 Goal

To explore how Machine Learning improves security in smart IoT environments.



## 🛠️ Tech Stack

* 📡 Wireless Networks
* 🌐 IoT Systems
* 🤖 Machine Learning


## 📊 Key Takeaways

* IoT systems are highly vulnerable without proper security
* Traditional security methods are not enough
* ML enables real-time and adaptive threat detection
